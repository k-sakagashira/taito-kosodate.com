手続きの書類をつくる

スマホで入力すると、子育て支援課に出す書類ができあがります。6種類の用紙に対応しています。

はじめに読んでください 台東区の公式サイトではありません。区の公開している様式をもとに、項目を再現した書類です。提出する前に、子育て支援課 給付担当（03-5246-1232）へ、この書式で受け付けてもらえるか確認してください。入力した内容はこの端末の中だけで処理され、送信も保存もしません。

「画像にする」を押すと、下に書類の画像が出ます。長押し（PCは右クリック）で保存して、コンビニのネットプリントなどで印刷できます。
